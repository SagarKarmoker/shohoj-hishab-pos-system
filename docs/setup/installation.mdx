# Installation

This page covers how to install and run Shohoj Hishab.

:::info
Detailed installation steps (e.g., Android/Flutter build, API setup) will be added as the project evolves.
:::

## Prerequisites

- Node.js 20+ (for API and tooling)
- pnpm 9+ (package manager)
- Android device or emulator (for mobile app, when available)

## Running the API

From the repository root:

```bash
pnpm install
pnpm dev
```

This starts the monorepo in development mode (API and other apps as configured).
