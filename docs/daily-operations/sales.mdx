# Sales & Daily Operations

Use Shohoj Hishab for day-to-day sales, billing, and payment collection.

## Billing

- One-tap item selection with icons
- Voice input (e.g., "2 kg rice, 1 liter oil") to add items
- Split payment: Cash + bKash in a single transaction
- SMS or thermal printer receipts

## Credit (Udhar) & Payments

- Track customer credit (baki)
- Send automated SMS reminders for pending payments
- Receive payments via bKash/Nagad/Rocket
