# Welcome to Shohoj Hishab

**Shohoj Hishab (সহজ হিসাব)** is a mobile-first Point of Sale system designed for small retailers in Bangladesh — kirana stores, cosmetics shops, mobile accessories, and clothing boutiques.

## Key features

- **Ultra-simple billing** — One-tap items, voice input, split payments (Cash + bKash)
- **Smart inventory** — Auto-deduct stock, low-stock alerts, expiry tracking
- **bKash / Nagad / Rocket** — QR payments, credit (udhar) tracking, SMS reminders
- **Offline-first** — Works without internet; syncs when connected
